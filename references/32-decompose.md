# 32 Decompose Mode

拆解模式严格只读，不生成改写稿。只读范围包括来源文件和当前 canon。允许创建总结、大纲、列表、图谱、时间线、地图和问题报告。若建议需要实施，必须开启新的辅写流程。

## 1. 完整流程

1. 确定进入拆解模式（请求清楚且无歧义时自动选定，无需额外模式确认）。
2. 读取并登记来源。
3. 确认人物图谱形式。
4. 确认时间线形式。
5. 确认地图与地点形式。
6. 确认四类列表版本。
7. 只读解析。
8. 生成总结。
9. 生成结构大纲。
10. 生成四类列表。
11. 生成人物图谱。
12. 生成时间线。
13. 生成地图与地点文件。
14. 输出一致性问题、矛盾点和待决项。
15. 建立版本目录并保存全部文件。

拆解结果不能修改 canon；发现 canon 问题时只输出建议。

## 2. 图谱选项

支持形式：
- 人物关系图。
- 阵营势力图。
- 人物与事件关系图。
- 人物与场景共现图。
- 人物关系矩阵。
- 人物阶段与弧光对照表。

规则：引用稳定编号，不依赖显示名称。

## 3. 时间线选项

支持形式：
- 世界历史时间线。
- 故事发生顺序。
- 叙述呈现顺序。
- 人物认知时间线。
- 事件因果时间线。
- 多人物并行时间线。

规则：
- 明确日期按日期排序。
- 只有相对时间时使用有向关系。
- 无法定位的事件进入 unplaced。
- 不同来源的冲突日期全部保留。
- 闪回、预言、传闻、记忆和现实事件分开。
- 不自动补齐日期，不自动合并相似事件。

## 4. 地图选项

支持形式：
- 世界地图。
- 区域地图。
- 城市与建筑地图。
- 交通路线图。
- 势力控制图。
- 地点拓扑关系图。
- 场景地点清单。

输出格式：
- 结构化地点数据。
- SVG。
- HTML 图册。
- PNG 等图片文件。

规则：地图数据是唯一 canon；SVG、HTML 和图片都是渲染结果。地点改名、易主、毁灭或迁移时新增状态，不覆盖历史。

## 5. 输出保存

- 分析结果保存为新的只读版本目录，不修改 canon。
- 四类列表使用作者选择的 `simple`、`standard`、`full` 级别。
- 一致性问题、矛盾点和待决项写入 `logs/open-questions.jsonl` 或版本报告。
